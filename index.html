How to host this page on GitHub Pages
  1. Make a repository. On github.com click the + (top right) → New repository. Name it something like lockbox, keep it Public, and create it.
  2. Upload the file. On the empty repository page click uploading an existing file, drag in index.html, and click Commit changes. The file must be named exactly index.html.
  3. Turn on Pages. Open Settings → Pages. Under Build and deployment set Source to Deploy from a branch, choose main and / (root), and save.
  4. Wait a minute or two. The Pages screen shows your address, like https://YOUR-NAME.github.io/lockbox/. A 404 at first just means it's still building.
  5. Set your code. On the live page open this panel, pick your numbers, click Use this code, then copy the link above and send it to your players.
  6. Updating later: open index.html in the repository, click the pencil, paste the new file over it, and commit. The site updates itself.
